# Vigia Cariacica

Site público do Vigia Cariacica: https://vigiacariacica.github.io

A gente mostra como a prefeitura de Cariacica usa o seu dinheiro. Olhamos as contas, perguntamos o que não está
claro e mostramos a resposta. Feito por moradores, sem partido e sem religião.

Este repositório só guarda as páginas prontas. Elas são geradas todo dia pelo robô do Vigia, a partir de dados
oficiais (IBGE, Tribunal de Contas do ES, Tesouro Nacional, Secretaria de Saúde de Cariacica e Ministério da
Saúde). Não edite à mão: a próxima atualização apaga a mudança.
